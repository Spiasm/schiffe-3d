# ⚓ Schiffe versenken 3D

Schiffe versenken mit drei Ebenen – ✈ Luft, 🚢 Wasser, ⚓ Tiefe – für zwei Android-Handys per Bluetooth.

## App herunterladen

**[👉 Neueste Version (Schiffe3D.apk)](https://github.com/Spiasm/schiffe-3d/releases/latest/download/Schiffe3D.apk)**

## Spielen

1. Handys einmal in den Bluetooth-Einstellungen koppeln.
2. Einer tippt „Spiel erstellen“, der andere „Spiel beitreten“ und wählt das Handy aus.
3. Flotte aufstellen, „Fertig“ tippen – los geht's.

## Flotte

| Ebene | Schiffe |
|---|---|
| ✈ Luft | Bomber (3), Jäger (2) |
| 🚢 Wasser | Schlachtschiff (4), Kreuzer (3), Zerstörer (2) |
| ⚓ Tiefe | U-Boot (3), Mini-U-Boot (2) |

Treffer = nochmal schießen. 📡 Radar (Luft) und 🔊 Sonar (Tiefe) je 1× pro Spiel: zeigen, wie viele Felder in einem 3×3-Bereich belegt sind.
